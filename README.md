# Utilities for Symbian devs  

Utilities for devs to develop for Symbian.

[emgfc/qembian](https://github.com/emgfc/qembian) - Seems very promising. You can run a full Symbian ROM and your agent can debug apps using sydb. [Reddit post](https://www.reddit.com/r/symbian/comments/1xpqzi8/seems_like_symbian_might_have_a_little_lifetime/)  
[EKA2L1](https://github.com/EKA2L1/EKA2L1) - The most famous emulator, more for games
